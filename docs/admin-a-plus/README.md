# CQRTV Admin Concept A+

Owner-review prototype only. This directory is a static visual study. It contains no production admin code, API calls, auth/session implementation, site-settings writes, user-management mutations, secrets, or admin bootstrap.

## Preview

Serve the repository root with a local static server and open `docs/admin-a-plus/`. The screen and size selectors show Dashboard, Users, Site Control, Admin Login, and icon comparison. Review captures target 1440×1000 desktop and 390×844 mobile. All sample users, metrics, and actions are fictional/local.

## Icon audit and rendering

The preview includes source SVG versus inline-duotone comparison, dark/light surface checks, seven semantic color states, and Logout/Exit candidates. Logout-6 is only a provisional visual candidate. Logout means ending an authenticated session; Exit means leaving a sub-area/context. They are separate actions.

The two icon layers use independent `--icon-primary` and `--icon-secondary` CSS variables after inlining the SVG. External `<img>` rendering cannot override hard-coded SVG fills with parent CSS variables, and CSS filters cannot reliably control two semantic colors. The prototype checks archived SVG markup for active/external content and inlines selected samples. No production icon is replaced.

CI inventories all archive SVGs, literal colors, gradients and masks, and groups semantic candidates for Logout, Exit, Login, Profile, Settings, Search, Notifications, Users, Dashboard, CS2, Messages, Social, Edit, Delete, Save, Upload, and Back. Candidate groups are discovery aids; final icon selection is subject to visual and accessibility review. Controls keep accessible names; decorative SVGs are hidden from assistive technology.

The action-to-source-to-candidate rationale for public and admin UI is in [icon-semantic-mapping.md](icon-semantic-mapping.md). It explicitly separates Login, Logout, and Exit; Logout-6 is provisional pending owner review.
