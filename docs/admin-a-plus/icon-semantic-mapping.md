# CQRTV icon semantic mapping — A+ review

This is an audit proposal for owner review. The mappings below do not change production files. “Current UI” describes existing public/admin uses observed in the PR #18 audit; “candidate” is an original archive asset proposed for its meaning. The complete archive inventory and filename candidate groups are generated by `qa/admin-a-plus-icon-audit.mjs` in CI.

| Action / state | Current public/admin use | Candidate source from `Icon Play CQRTV.rar` | Reason and status |
| --- | --- | --- | --- |
| Dashboard overview | Generic grid/home glyph; admin uses `Widget--playcqrtv.svg` | `Settings Fine Tuning/Widget--playcqrtv.svg` | Clear overview metaphor; retain. Use `Business Statistic/Chart--playcqrtv.svg` for charts only. |
| Users / team | Generic people glyph; admin uses `Users-Group-Rounded` | `Users/Users-Group-Rounded--playcqrtv.svg` | Group means a list/team; `User--playcqrtv.svg` stays for one profile. |
| Profile / account | Initial/avatar circle or generic user | `Users/User-Circle--playcqrtv.svg` | Stronger person/profile meaning; fallback only, not a replacement for player avatar or Steam identity. |
| Settings | Generic gear/settings icon | `Settings Fine Tuning/Settings-Minimalistic--playcqrtv.svg` | Direct settings meaning; retain for settings controls. |
| Search | Generic magnifier | `Search/Magnifer--playcqrtv.svg` | Direct search meaning; keep distinct from a filter action. |
| Notifications | Generic bell or placeholder | `Notifications/Bell--playcqrtv.svg` | Clear notifications meaning. Not a claim that notification delivery works. |
| Login | Generic arrow or a reversed logout shape | `Arrows Action/Login--playcqrtv.svg` (compare `Login-6--playcqrtv.svg`) | Represents entering an account; do not mirror Logout semantics. |
| Logout / end session | Admin currently uses `Arrows Action/Logout--playcqrtv.svg`; preview compares it with alternatives | **Provisional:** `Arrows Action/Logout-6--playcqrtv.svg` | Candidate has a clearer “leave through a door” reading in this preview. Owner must confirm direction/meaning before any production replacement. |
| Exit / leave a sub-area | Often conflated with logout | `Arrows Action/Exit--playcqrtv.svg` | Separate meaning: leave a screen/context; does not claim the authenticated session ended. |
| Email field | Hand-drawn envelope or generic mail glyph | `Messages Conversation/Letter--playcqrtv.svg` | Email address entry. |
| Email confirmed | Plain gray envelope or check alone | `Messages Conversation/Letter-Opened--playcqrtv.svg` with visible status text | Distinguishes verification state; text remains the accessible status. |
| Password / protected session | Generic lock/shield used interchangeably | `Security/Lock-Keyhole-Minimalistic--playcqrtv.svg`; `Security/Shield-User--playcqrtv.svg` | Lock means password, shield means protected admin identity/session. |
| Password visibility | Generic eye | `Security/Eye--playcqrtv.svg` / `Security/Eye-Closed--playcqrtv.svg` | Paired visible/hidden state; accessible label and `aria-pressed` must change with the icon. |
| CS2 / matchmaking | Generic gamepad, play triangle and ranking icons used in different contexts | `Electronic Devices/Gamepad-Minimalistic--playcqrtv.svg`; `Video Audio Sound/Play--playcqrtv.svg`; `Sports/Ranking--playcqrtv.svg` | Gamepad means game/match area, play means start, ranking means competitive standings. Do not imply the queue is live where it is not. |
| Messages / chat | Generic speech bubble or mail | `Messages Conversation/Chat-Round--playcqrtv.svg` | Chat/conversation only; use Letter for email. |
| Social platform link | Generic chat fallback for all providers | Provider-specific source icon when present; otherwise a labeled text link | Preserve the provider identity. Do not replace Steam/social logos with a misleading generic CQRTV icon. |

| Suspend user | Trash/delete glyph or generic warning | `Users/User-Block--playcqrtv.svg` | Reversible suspension/blocking, not deletion. |
| Delete | Currently text-led; should not reuse suspend icon | Candidate: `Essentional UI/Trash-Bin-Minimalistic-4--playcqrtv.svg` (verify exact file in archive index) | Destructive operation requires explicit confirmation and text. Candidate is not approved for production. |
| Save | Text submit button | Candidate: `Files/Diskette--playcqrtv.svg` (verify exact file in archive index) | Only use where the action is actually Save; keep the visible “Сохранить” label. |
| Upload | Text/file input or generic arrow | `Arrows Action/Upload--playcqrtv.svg` | Arrow entering the system matches file upload. |
| Back | Browser/link arrow | `Arrows/Alt-Arrow-Left--playcqrtv.svg` | Navigation back; distinct from close, exit, and logout. |
| Close dialog | X glyph | `Essentional UI/Close-Circle--playcqrtv.svg` | Close current dialog; does not mean leave page/session. |
| Country selection | Country flag | Keep the country flag image plus readable country name | A flag is meaningful data, not a generic action icon; preserve text/fallback. |

Archive paths for less common candidates can differ by directory/capitalization. The CI inventory artifact records every exact source path, literal colors, gradient/mask presence, and filename-based semantic group. The owner should compare candidate art in that artifact before approving any source-to-alias mapping. `Logout-6` remains a preview choice only.
